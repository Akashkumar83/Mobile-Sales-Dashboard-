Mobile Sales Dashboard | Power BI

An interactive Power BI dashboard designed to analyze mobile sales performance and business insights. This project visualizes total sales, total quantity, transactions, customer ratings, payment methods, and city-wise sales distribution. It includes interactive filters for mobile models, brands, payment methods, months, and days, helping users explore sales trends, understand customer preferences, and monitor business performance through clear and dynamic visualizations.


Project Objectives

Analyze overall mobile sales performance.

Track total sales, quantity sold, and number of transactions.

Identify sales trends by month and day.

Compare sales performance across mobile models and brands.

Understand customer ratings and payment preferences.

Explore geographical sales distribution across cities.



How to Use

Download or clone this repository.

Open the .pbix file using Power BI Desktop.

Explore the dashboard using the available slicers and filters.

Select different mobile models, payment methods, brands, months, and days to analyze the data.
